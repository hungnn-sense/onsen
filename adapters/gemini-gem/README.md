# Gemini Gem

1. Gemini → **Gem manager → New Gem**.
2. Instructions: dán khối trong `../chi-dan-tro-ly.md`.
3. Knowledge: tải `../onsen-knowledge-bundle.md` (tạo lại bằng `bash adapters/build-bundle.sh`).
4. Lưu Gem → chat → "thiết lập hồ sơ" → lưu Thẻ hồ sơ vào Saved info / cuối Instructions.

Bản free: trí nhớ yếu → dán lại Thẻ hồ sơ khi cần. Không duyệt web → tự dán quảng cáo cần phân tích.
