# Claude Code

1. `git clone <URL-repo> onsen && cd onsen` (hoặc tải ZIP, giải nén).
2. Mở thư mục `onsen` bằng Claude Code. `CLAUDE.md` tự nạp.
3. Gõ: "thiết lập hồ sơ". Hồ sơ lưu `brain-template/doanh-nghiep.md`.

Dùng: giao việc bằng ngôn ngữ tự nhiên. Mỗi sản phẩm/chiến dịch: copy `brain-template/chien-dich/_mau-chien-dich.md` thành file riêng.
