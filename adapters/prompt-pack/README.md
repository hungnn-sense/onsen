# Prompt pack

Chạy mọi chatbot, không cài đặt.

1. Lần đầu: dán **Prompt 0** trong `bo-prompt.md`, trả lời → nhận Thẻ hồ sơ, lưu lại.
2. Mỗi lần: dán Thẻ hồ sơ + prompt của việc cần làm (trong `bo-prompt.md`), điền `[…]`.

Hạn chế: không tự nhớ giữa phiên (dán lại Thẻ hồ sơ); không tự duyệt web (tự dán dữ liệu).
