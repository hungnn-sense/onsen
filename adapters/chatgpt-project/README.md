# ChatGPT Project

1. ChatGPT → **+ New project**.
2. Instructions: dán khối trong `../chi-dan-tro-ly.md`.
3. Files: tải `../onsen-knowledge-bundle.md` (hoặc chạy `bash adapters/build-bundle.sh` để tạo lại).
4. Mở chat trong Project → "thiết lập hồ sơ" → lưu Thẻ hồ sơ vào Instructions/bộ nhớ.

Bản free: giới hạn file/bộ nhớ/lượt; Onsen "quên" thì dán lại Thẻ hồ sơ. Không duyệt web → tự dán quảng cáo cần phân tích.
