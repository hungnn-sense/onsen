# Onsen

Bộ cấu hình trợ lý. Chạy trên Claude (Projects), ChatGPT Project, Gemini Gem, Claude Code, hoặc chatbot bất kỳ.

## Dùng
Xem `adapters/` và chọn theo công cụ:
- `adapters/claude-project/`
- `adapters/claude-code/`
- `adapters/chatgpt-project/`
- `adapters/gemini-gem/`
- `adapters/prompt-pack/`

Thiết lập lần đầu: mở trợ lý và yêu cầu "thiết lập hồ sơ".

Video animation (dựng ra MP4): chỉ bản Claude Code — `cong-cu/video-animation/`.
